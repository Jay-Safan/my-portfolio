# jaysafan.dev — Personal Portfolio

Personal portfolio for **Muhammad Jay Safan**, a fullstack & mobile developer open to remote and global opportunities.

## Stack

- **React** + **Vite**
- **Tailwind CSS** (via `@tailwindcss/vite`)
- **Geist / Geist Mono** fonts
- **Formspree** for contact form (no backend)

## Sections

- **Hero** — tagline, CTAs, availability badge
- **Projects** — ErgoPrima company website + upcoming projects
- **Skills** — Frontend, Backend, Tools
- **About** — bio, portrait, stats
- **Contact** — validated form wired to Formspree
- **Footer** — GitHub, LinkedIn, email

## Dev

```bash
npm install
npm run dev      # localhost:5173
npm run build    # production build → dist/
npm run preview  # preview production build
```

## Design

Warm off-white / deep navy palette with muted amber accent. Dark mode supported (persisted via localStorage, respects system preference).

| Token  | Light               | Dark          |
|--------|---------------------|---------------|
| paper  | `#FAF9F7`           | `#0E1118`     |
| ink    | `#0E1525`           | `#F0EEE8`     |
| accent | `#C28E5A` (amber)   | same          |
